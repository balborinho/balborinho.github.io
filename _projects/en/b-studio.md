A simple tool for managing animation projects, organising production tasks, and tracking progress through the different stages of the animation pipeline. It helps structure projects, manage tasks, and keep production information organised in one place.

Data is stored locally in the browser and can be imported and exported in JSON format, making it possible to create backups and transfer project information between devices.

Try it <a class="home-card__link" href="https://balborinho.com/B-Studio/">here</a>. The source code is available in the <a class="home-card__link" href="https://github.com/balborinho/B-Studio">GitHub repository</a>.
